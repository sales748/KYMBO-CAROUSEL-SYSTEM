# Batch 01v2 — scene photo shot list

**24 photos across 4 scenes.** Every prompt below is complete and copy-paste-ready — style lines are baked in. Paste one prompt at a time into nanobananapro.

## Generation settings

- **Tool:** nanobananapro
- **Resolution:** 2K (longer edge)
- **Aspect:** **4:5**, exactly (not 1:1, not 3:4)
- **Format:** PNG
- **Output filenames:** `s1.png` … `s6.png` in each scene's folder
- **No outpaint / letterbox / extension.** If the tool offers to extend a shorter frame, regenerate — never accept the extension (it always seams).
- **No dark band, no vignette, no black rectangle at the bottom.** A CSS gradient handles text legibility on top; the photograph fills the ENTIRE 4:5 frame with natural scene content.
- **Compose subject in the upper 55-60%.** The lower 40% carries type; keep it filled with natural scene content, not blank floor.
- **No text on surfaces. No logos. No clearly identifiable faces.** Backs of heads, hands, over-the-shoulder crops are fine.

## Composite slides — the blank-screen rule

Some slides mount a Kymbo booking-app UI onto a device's screen via a CSS perspective transform. For those photos:

- Device must be **PERFECTLY STRAIGHT AND FRONT-ON. Zero rotation. Zero tilt.**
- Screen must be **BLANK white / uniformly light.** No mockup UI, no wallpaper, no glare that draws attention. The Kymbo overlay maps onto that clean rectangle later — if a UI is already there, the composite fails.

**Composite slides in this batch:** scene-21 s2 (phone) and scene-21 s5 (laptop). Every other slide is a pure photo.

# QA checklist (per photo, before you accept it)

- [ ] Aspect is 4:5 (measure — don't trust the tool's default)
- [ ] No dark band, no vignette, no black rectangle anywhere in the frame
- [ ] Photo fills the frame edge-to-edge; the lower 40% still has natural scene content
- [ ] For composite slides: device is straight-on with zero tilt, screen is blank white
- [ ] No visible text on any surface, no logos, no faces
- [ ] Style reads consistent with the other slides in the same scene — same photographer, same lens, same neutral daylight

# Delivery

1. Drop the 24 files into the four folders above using the exact filenames (`s1.png` … `s6.png`).
2. Ping when the four folders are populated.
3. `npm run build` composes the device overlays and exports the final slide PNGs and export bundle.
