Read **`profiles/kymbo/build/prompts/VISUAL.md`** first for the palette, character rules, and prohibition catalogue. Every prompt below runs on top of it.

## Generation settings (apply to every photo)

- **Tool:** nanobananapro
- **Resolution:** 2K longer edge
- **Aspect:** **4:5**, exactly. Never 1:1, never 3:4, never letterboxed.
- **Format:** PNG.
- **Filenames:** `s1.png` … `s6.png` in each scene's asset folder.
- **No outpaint / extend / letterbox.** If the tool asks to extend a short frame, regenerate — never accept.

## Composite slides — the blank-screen rule

One slide in this batch is a device composite (scene-21 s2 — phone). The screen must be **BLANK white**, naturally lit, zero UI. The Kymbo booking-app UI composites on top later via CSS perspective transform. Zero tilt, zero rotation, straight-on.

## Kill list (recap from VISUAL.md — verify every photo)

Before accepting any image, run through:

- ❌ Succulents (any kind, any pot)
- ❌ Round white ceramic pots
- ❌ Fiddle-leaf figs, monstera, rubber trees
- ❌ Jute or sisal rugs
- ❌ Terrazzo, marble slabs, "material moodboard" surfaces
- ❌ Perfectly stacked photogenic books
- ❌ Fresh-cut flowers in clear glass vases
- ❌ Pastel walls (teal / sage / blush / cream cast)
- ❌ Symmetric three-object triangles
- ❌ Centered composition on an empty desk
- ❌ Soft, even, uncharacterized daylight
- ❌ Blown-out backlit windows
- ❌ Apple-product tastemaker signals
- ❌ Motivational wall art or visible text
- ❌ "Documentary workspace" (wooden desk + laptop + notebook + mug — that's the median slop we're refusing)

# QA checklist (run per photo)

1. Is there a succulent, fiddle-leaf, or houseplant anywhere? Reject.
2. Is there a jute or sisal rug? Reject.
3. Is the wall or dominant surface teal / sage / pastel / blush? Reject.
4. Is the object arrangement symmetric (three-object triangle)? Reject.
5. Is the light soft, even, shadowless? Reject.
6. Does the shadow side of the subject go near-black, or muddy gray? If gray, reject.
7. Is the scene "clean and staged" or "specific and worked-in"? If clean, reject.
8. For scene-21 s2 (composite): device zero-tilt, screen blank white? If tilted or UI is on it, reject.
9. Does the subject read as ENGINEERED / MECHANICAL / MACHINED — or does it read as "documentary workspace"? If workspace, reject.
