**Carousel:** scene-01 · **Pillar:** The Problem · **Path B (scene / organic)**

Palette-lock every render to navy #262B38 shadows + warm cream #F7F8EA, muted/desaturated so lime + text pop. 4:5 (1080x1350). No text, no logos, no watermarks in the image. Generic scenes only — never a real, identifiable person.

Drop each render into `assets/scene-01/` as `s1.png … s6.png`, then re-run `npm run build`.
