# Scene 01 — drop your ChatGPT renders here

Generate each image from the prompts in `build/prompts/scene-01.md`, then save
them in this folder as:

```
s1.png  s2.png  s3.png  s4.png  s5.png  s6.png
```

Then run `npm run build`. The renders replace the placeholders automatically —
the type and organic accents are already positioned on top.
